# CompraKi — Modelagem de Ameaças e Segurança de Software

Trabalho da disciplina Software Seguro, cobrindo as sete etapas do enunciado: modelagem de ameaças (STRIDE), análise de riscos (NIST CSF 2.0), arquitetura segura, código seguro, verificação de vulnerabilidades, detecção de intrusões e DevSecOps.

Sistema analisado: **CompraKi**, um marketplace de e-commerce (clientes, vendedores terceiros e administração da plataforma).
